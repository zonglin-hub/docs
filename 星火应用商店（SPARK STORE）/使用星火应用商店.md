# Ubuntu 26.04 上使用星火应用商店

社区用户报告了在 Ubuntu 26.04 上使用星火应用商店时遇到的几个典型问题，并提供了对
应的解决方法。可以关注[星火应用商店的官方论坛](https://bbs.spark-app.store)

*   **商店无法启动或安装失败**

    ```bash
    sudo apt update
    sudo apt --fix-broken install # 修复依赖并重新安装
    sudo apt install ./spark-store_5.2.1.0_amd64.deb
    ```

*   **商店内功能异常或应用无法运行**

    ```bash
    # 可以尝试使用以下命令启动星火商店，以绕过潜在的图形加速问题
    sudo spark-store --disable-gpu
    ```

SPARK APM 是星火应用商店 v5.0 及以后版本引入的**核心底层技术**，可以理解为星火商
店为了在更多 Linux 发行版上实现“安装即用”而自研的一套**容器化软件包管理系统**。

### 🧩 SPARK APM 是什么？

它的全称是 **Amber Package Manager**，因 Logo 为琥珀色而得名“琥珀包”。它是一套**
基于容器技术、与主机环境隔离的软件包管理系统**，旨在提供类似如意玲珑（Linyaps）
或 Flatpak 的应用体验。

### ⚙️ 它是如何工作的？

APM 的核心思路是“**在兼容中隔离**”，通过三部分实现：

*   **容器启动**：使用 `bwrap`（bubblewrap）创建一个极轻量级的容器沙箱。
*   **容器融合**：利用 `fuse-overlayfs` 将基础环境（Base）和应用内容（Core）**层
    叠拼接**，形成完整运行环境。
*   **依赖管理**：底层仍然使用 **`apt`/`dpkg`** 来管理软件包。

这意味着，APM 在保留 Debian 生态兼容性的同时，通过容器隔离解决了依赖冲突问题。

### 🔗 它与星火应用商店是什么关系？

*   **APM 是底层引擎**：负责实际的安装、隔离和运行。
*   **星火商店是前端界面**：你看到的图形化商店，是 APM 的**图形客户端**。商店下
    载的应用，最终由 APM 来安装和管理。

你之前安装的 `spark-store 5.3.1`，其核心工作就是调用 APM 来管理应用。

### 💡 APM 的优势是什么？

*   **跨发行版兼容**：得益于容器隔离，APM 理论上可在 **Arch、Fedora、openSUSE、
    银河麒麟、统信 UOS** 等多种发行版上运行，而不局限于 Debian 系。
*   **磁盘占用更小**：相比 Flatpak 或玲珑，APM 的设计目标之一就是**牺牲更小的存
    储空间**，来换取更好的兼容性和易用性。
*   **隔离与干净卸载**：应用文件被保存在独立目录（如 `~/.apm/包名`），卸载时清理
    更彻底，避免系统残留。


你在星火商店里看到的 `SPARK` 和 `APM`，代表了两种不同的软件打包和分发格式。你可
以把它们理解为商店里的“**两种商品来源**”，**APM是星火力推的、更现代的新格式，而
SPARK则是传统的、兼容性更广的旧格式**。
