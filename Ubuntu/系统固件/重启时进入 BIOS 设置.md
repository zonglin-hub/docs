在 Ubuntu 24.04 中，虽然没有一个“万能”命令能保证在所有电脑上 __直接重启并毫无例
外地进入 BIOS__，但有一个命令可以 __告诉系统“下次重启时请尝试进入 BIOS 设置”__。
最推荐你使用这个现代且高效的方法：

### ⚡ 首选命令：systemctl reboot --firmware-setup

在终端中输入以下命令：

```bash
sudo systemctl reboot --firmware-setup
```

- __命令作用__：这个命令会 __立即重启你的电脑__，并向系统固件（UEFI/BIOS）发送一
  个请求，要求它进入设置界面。__能否成功进入，最终取决于你的主板固件是否支持此功
  能__。绝大多数支持 UEFI 的现代电脑（过去十年内的产品）都可以很好地响应这个命
  令。

- __工作原理__：
  - `systemctl` 是管理系统和服务的命令。
  - `reboot` 参数表示重启，
  - `--firmware-setup` 选项则指示系统在重启后尝试进入固件设置。
